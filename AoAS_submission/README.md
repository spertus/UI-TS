## How to rerun

Do not run the scripts inside this directory: they write their CSVs to the current directory, which would break
the seal. Copy the directory somewhere else first:

```bash
cp -R AoAS_submission /tmp/aoas && cd /tmp/aoas/Code
```

| Script | Command (from `Code/`) | Output |
|---|---|---|
| `significance_simulations.py` | `python significance_simulations.py` | `significance_simulation_results.csv` |
| `pointmass_simulations.py` | `python pointmass_simulations.py` | `point_mass_results.csv` |
| `bernoulli_simulations.py` | `mkdir -p Bernoulli_Results; for i in $(seq 1 100); do SLURM_ARRAY_TASK_ID=$i python bernoulli_simulations.py; done` | `Bernoulli_Results/bernoulli_results_parallel_<task>_9.csv` |
| `gaussian_simulations.py` | `mkdir -p Gaussian_Results; for i in $(seq 1 50); do SLURM_ARRAY_TASK_ID=$i python gaussian_simulations.py; done` | `Gaussian_Results/gaussian_simulation_results_parallel_<task>_9.csv` |
| `peak_comparison_simulation.py` | `python peak_comparison_simulation.py` | `peak_comparison_results.csv` |
| `pgd_time.py` | `python pgd_time.py` | `pgd_run_times_short.csv` |

- **Bernoulli and Gaussian simulations.** These were run as SLURM array jobs, one task per value of
  `SLURM_ARRAY_TASK_ID`, which also sets the random seed. Each task runs 10 replicates and writes one CSV, named
  after its last replicate. The loops above do the same thing serially. `Results/all_bernoulli_simulations.csv`
  holds tasks 1-100 except task 86 (99 tasks), and `Results/all_gaussian_simulations.csv` holds tasks 1-50. The
  per-task CSVs were concatenated with pandas, keeping the row index as the unnamed first column, which
  `r_plots.R` drops:

  ```python
  import glob, pandas as pd
  pd.concat([pd.read_csv(f) for f in sorted(glob.glob("Bernoulli_Results/*.csv"))]).to_csv("all_bernoulli_simulations.csv")
  ```

- **Plots and tables.** `r_plots.R` reads its inputs from the working directory. Run it from the copied
  `Results/` directory (for example, `setwd("/tmp/aoas/Results")` and then `source("../Code/r_plots.R")`, or
  step through it section by section). It draws the plots on screen and prints LaTeX tables with `xtable`. The
  PNGs in `Plots/` were exported from these plots by hand. Two sections of `r_plots.R` read files that are not in
  the tagged commit (`intersection_null_stopping_times.csv` and `pgd_run_times_short.csv`); neither feeds a
  figure or table in v5.
- **Randomness.** `bernoulli_simulations.py` and `gaussian_simulations.py` seed NumPy with the task ID, and
  `peak_comparison_simulation.py` seeds it with 0. `significance_simulations.py` does not set a seed, so its
  Monte Carlo estimates vary slightly from run to run. The point-mass populations are constant, so the sample
  sizes from `pointmass_simulations.py` are deterministic (its run times are not).
